# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 개인 프로필 및 포트폴리오를 소개하는 웹사이트 |
| 대상 개발자 | 최수나 |
| 이메일 | ccsna537@gmail.com |
| 주 개발 분야 | 바이브코딩, Python, HTML5 |
| 기술 스택 | HTML5, CSS3, Vanilla JavaScript (프레임워크·빌드 도구 미사용) |
| 배포 형태 | 정적 웹사이트 (GitHub Pages, Netlify 등 정적 호스팅 가능) |

### 1.1 배경
바이브코딩(AI와 대화하며 코드를 만드는 개발 방식), Python, HTML5를 주력으로 하는 개발자 최수나의 역량과 작업물을 한곳에서 보여주고, 방문자가 쉽게 연락할 수 있는 개인 웹사이트가 필요하다.

### 1.2 목표
- 방문자가 10초 안에 "누구이고, 무엇을 하는 개발자인지" 파악할 수 있다.
- 대표 프로젝트를 카드 형태로 보여주고 직접 실행해 볼 수 있게 연결한다.
- 이메일 등으로 손쉽게 연락할 수 있다.
- 서버 없이 정적 파일만으로 동작하며, 데스크톱과 모바일 모두에서 잘 보인다.

### 1.3 비목표 (이번 범위 제외)
- 블로그, 댓글, 회원가입 등 서버가 필요한 기능
- 다국어 전환 (초기에는 한국어 단일)
- CMS 및 관리자 페이지

## 3. 사이트 구조 (단일 페이지, 섹션 스크롤)

상단 고정 내비게이션으로 각 섹션에 앵커 이동한다.

| 순서 | 섹션 | 내용 |
|------|------|------|
| 1 | Hero | 이름 "최수나", 한 줄 소개, 주력 분야 태그(바이브코딩 · Python · HTML5), 프로젝트 보기 / 연락하기 버튼 |
| 2 | About | 짧은 자기소개, 개발 철학, 바이브코딩 접근 방식 소개 |
| 3 | Skills | 분야별 기술 카드 (아래 3.1 참고) |
| 4 | Projects | 프로젝트 카드 목록 (아래 3.2 참고) |
| 5 | Contact | 이메일 링크, 메일 보내기 버튼, 이메일 주소 복사 버튼 |
| 6 | Footer | 저작권 표기, 맨 위로 이동 링크 |

### 3.1 Skills 섹션
- **바이브코딩:** AI 협업 개발, 프롬프트 설계, 요구사항 정리(PRD) 작성, 빠른 프로토타이핑
- **Python:** 스크립트/자동화, 데이터 처리, 간단한 게임 및 GUI(tkinter)
- **HTML5:** 시맨틱 마크업, Canvas, CSS3, JavaScript 게임/인터랙션

각 항목은 아이콘 또는 이모지, 제목, 설명, 숙련도 표시(막대 또는 레벨 배지)로 표현한다.
※ 숙련도 수치와 세부 항목은 실제 경험에 맞게 최수나가 확인·수정한다.

### 3.2 Projects 섹션
프로젝트는 `projects` 데이터 배열(JS 또는 JSON)로 관리하여 추가/수정이 쉽도록 한다. 카드 구성: 썸네일, 제목, 설명, 사용 기술 태그, 링크 버튼(데모 / 소스).

## 5. 디자인 가이드

### 5.1 콘셉트
깔끔하고 현대적인 미니멀 스타일에 "코드 + AI 협업" 느낌을 살린 포인트(모노스페이스 폰트 강조, 터미널 풍 타이핑 효과 등).

### 5.2 컬러 (초안)
| 용도 | 다크 | 라이트 |
|------|------|--------|
| 배경 | `#0d1117` | `#ffffff` |
| 패널/카드 | `#161b22` | `#f6f8fa` |
| 본문 텍스트 | `#e6edf3` | `#1f2328` |
| 보조 텍스트 | `#8b949e` | `#59636e` |
| 포인트 | `#58a6ff` | `#0969da` |

CSS 변수(`:root`)로 정의하여 테마 전환 시 값만 교체한다.

### 5.3 타이포그래피
- 본문: `Pretendard`, `Malgun Gothic`, `system-ui`, sans-serif
- 제목/코드 느낌 요소: `Consolas`, `JetBrains Mono`, monospace
- 외부 폰트 사용 시 웹폰트 로딩 실패에 대비한 대체 폰트를 지정한다.

### 5.4 레이아웃
- 콘텐츠 최대 너비 1100px, 좌우 여백 16px 이상
- 브레이크포인트: 모바일 ≤ 600px / 태블릿 ≤ 900px / 데스크톱 > 900px
- 프로젝트 카드: 데스크톱 3열 → 태블릿 2열 → 모바일 1열 (CSS Grid)

## 6. 비기능 요구사항

- **성능:** 외부 라이브러리 없이 가볍게 유지하고, Lighthouse Performance 90점 이상을 목표로 한다. 이미지는 적절한 크기로 최적화하고 `loading="lazy"`를 적용한다.
- **접근성:** 시맨틱 태그(`header`, `nav`, `main`, `section`, `footer`) 사용, 이미지 `alt` 제공, 충분한 색상 대비(WCAG AA), 키보드 탐색과 포커스 표시 지원, `prefers-reduced-motion` 시 애니메이션 최소화.
- **호환성:** 최신 Chrome, Edge, Firefox, Safari 및 모바일 브라우저.
- **보안/개인정보:** 이메일은 공개 연락처로 노출하며, 스팸 우려 시 이후 문의 폼으로 대체할 수 있다. 외부 링크에는 `rel="noopener noreferrer"`를 적용한다.

## 7. 기술 설계

### 7.1 폴더 구조
```
DemoPort/
├── prd.md              # 본 문서
├── index.html          # 단일 페이지 진입점
├── css/
│   └── style.css       # 스타일 (CSS 변수, 반응형, 테마)
├── js/
│   ├── main.js         # 내비, 스크롤 효과, 테마 전환, 이메일 복사
│   └── projects.js     # 프로젝트 데이터 배열 및 카드 렌더링
├── assets/
│   ├── images/         # 프로필 사진, 프로젝트 썸네일
│   └── favicon.svg
└── projects/           # (선택) 제작한 게임 데모를 함께 배치
    ├── snake/
    └── tetris/
```

### 7.2 프로젝트 데이터 예시
```js
const projects = [
  {
    title: "테트리스",
    description: "홀드, 고스트 피스, 레벨 시스템을 갖춘 웹 테트리스",
    tags: ["HTML5", "Canvas", "JavaScript"],
    demo: "projects/tetris/tetris.html",
    source: null,
    thumbnail: "assets/images/tetris.png",
  },
  // ...
];
```

### 7.3 주요 구현 포인트
- 테마: `<html data-theme="dark|light">` 속성과 CSS 변수로 전환, 깜빡임 방지를 위해 `<head>`에서 초기 테마를 먼저 적용한다.
- 스크롤 애니메이션: `IntersectionObserver` 사용.
- 이메일 복사: `navigator.clipboard.writeText`, 실패 시 `mailto:` 링크로 대체.
- 현재 섹션 강조: `IntersectionObserver`로 화면에 보이는 섹션을 감지하여 내비 항목에 활성 클래스 부여.

## 10. 리스크 및 고려사항
- **콘텐츠 부족:** 프로필 사진, 자기소개 문구, 프로젝트 썸네일은 최수나가 제공해야 한다. 준비 전에는 임시(플레이스홀더) 콘텐츠를 사용한다.

- **숙련도 표기의 신뢰성:** 수치화된 숙련도는 오해를 줄 수 있어, 막대 대신 "사용 경험 설명" 방식으로 바꿀 수 있다.
