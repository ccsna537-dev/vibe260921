# PRD: 종스크롤 슈팅 게임 (제비우스 스타일)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | game01 |
| 장르 | 종스크롤(수직 스크롤) 슈팅 게임 |
| 레퍼런스 | 제비우스(Xevious, 1982) |
| 기술 스택 | HTML5 Canvas, CSS3, Vanilla JavaScript (ES6+) |
| 플랫폼 | 데스크톱 웹 브라우저 (Chrome, Edge, Firefox 최신 버전) |
| 외부 의존성 | 없음 (빌드 도구·프레임워크·라이브러리 미사용) |

### 1.1 목적
별도 설치나 빌드 없이 `index.html`을 열면 바로 실행되는, 제비우스 특유의 플레이 감각(공중/지상 이중 공격, 끊임없이 스크롤되는 지형)을 가진 웹 슈팅 게임을 만든다.

### 1.2 목표
- 브라우저에서 60 FPS로 부드럽게 동작한다.
- 공중 적과 지상 적을 서로 다른 무기로 공격하는 제비우스의 핵심 재미를 구현한다.
- 코드는 모듈 단위로 분리되어 이후 스테이지·적·아이템을 쉽게 추가할 수 있다.

### 1.3 비목표 (이번 범위 제외)
- 모바일 터치 조작, 온라인 랭킹, 멀티플레이
- 서버 연동, 계정 시스템
- 정식 그래픽 리소스 제작 (초기 버전은 Canvas 도형/간단한 스프라이트로 표현)

## 2. 핵심 게임 규칙

### 2.1 플레이 방식
- 화면은 위에서 아래로 끊임없이 스크롤되며, 플레이어는 화면 하단부의 전투기를 조작한다.
- 플레이어는 **공중 공격(Zapper)** 과 **지상 폭격(Blaster)** 두 가지 무기를 동시에 사용한다.
  - 공중 공격: 전방으로 발사되는 연사 탄. 공중 적에게만 유효.
  - 지상 폭격: 조준점(Crosshair)이 표시된 전방 일정 거리에 투하되는 폭탄. 지상 적에게만 유효.
- 적의 탄 또는 적 본체에 닿으면 생명이 1 감소한다.
- 모든 생명을 잃으면 게임 오버.

### 2.2 조작

| 입력 | 동작 |
|------|------|
| 방향키 / WASD | 8방향 이동 |
| `Space` (누르고 있기) | 공중 공격 연사 |
| `X` 또는 `Z` | 지상 폭격 투하 |
| `P` | 일시정지 / 해제 |
| `Enter` | 시작 / 게임 오버 후 재시작 |

### 2.3 플레이어
- 초기 생명: 3
- 이동 속도: 약 300 px/s
- 피격 후 2초간 무적(깜빡임 표시), 시작 위치에서 부활
- 공중 탄 연사 간격: 약 150 ms, 폭탄 재사용 대기: 약 400 ms
- 이동 범위는 화면 안으로 제한

### 2.4 적

**공중 적 (공중 공격으로 격파)**

| 이름 | 행동 | 체력 | 점수 |
|------|------|------|------|
| Toroid | 화면 위에서 등장해 사인 곡선으로 좌우 이동 | 1 | 100 |
| Torkan | 편대(3~5기)로 직선 하강 후 이탈 | 1 | 150 |
| Kapi | 플레이어 방향으로 선회하며 접근 | 2 | 300 |

**지상 적 (지상 폭격으로 격파)**

| 이름 | 행동 | 체력 | 점수 |
|------|------|------|------|
| Turret | 고정 위치, 플레이어를 향해 일정 주기로 조준 사격 | 1 | 200 |
| Tank | 지형과 함께 스크롤되며 느리게 이동 | 2 | 300 |
| Radar | 고정, 공격 없음 (점수용 목표물) | 1 | 500 |

**보스**
- Andor Genesis급 대형 보스를 스테이지 끝에 등장시킨다.
- 공중 공격은 무효, 지상 폭격만 유효하며 여러 발이 필요하다 (체력 약 20).
- 처치 시 스테이지 클리어.

### 2.5 아이템 (선택 구현)
- 특정 지상 적 파괴 시 드롭: 생명 +1, 점수 보너스, 연사 속도 증가.

### 2.6 점수
- 적 처치 시 위 표의 점수를 획득한다.
- 10,000점마다 생명 +1 (최대 5).
- 최고 점수는 `localStorage`에 저장하고 타이틀 화면에 표시한다.

### 2.7 난이도
- 시간이 지날수록 적 출현 빈도와 적 탄 속도가 점진적으로 증가한다.
- 스테이지가 올라갈수록 스크롤 속도와 보스 체력이 증가한다.

## 3. 화면 구성

### 3.1 화면(상태) 흐름
```
[타이틀] --Enter--> [플레이] --생명 0--> [게임 오버] --Enter--> [타이틀/재시작]
                      |  ^
                      P  P
                      v  |
                    [일시정지]
```

### 3.2 캔버스
- 논리 해상도: 480 x 720 (세로형, 2:3 비율)
- 브라우저 창 크기에 맞춰 비율을 유지하며 CSS로 확대/축소
- 배경은 검정으로 두고 캔버스를 화면 중앙에 배치

### 3.3 HUD
- 좌상단: 현재 점수
- 상단 중앙: 최고 점수
- 좌하단: 남은 생명 (전투기 아이콘)
- 우상단: 스테이지 번호

### 3.4 배경 스크롤
- 다층 패러랙스 스크롤: 원경(느림) / 지형(중간)
- 지형은 타일 기반으로 랜덤 조합하여 무한 반복 (숲, 강, 도로, 평원, 구조물)
- 지상 적은 지형 스크롤 속도와 동일하게 이동하여 지면에 붙어 있는 느낌을 준다.

## 4. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|----|----------|----------|
| F-01 | 게임 루프: `requestAnimationFrame` 기반, delta time을 사용해 프레임률과 무관한 속도 유지 | 필수 |
| F-02 | 키보드 입력 처리(다중 키 동시 입력 지원) | 필수 |
| F-03 | 플레이어 이동/발사/폭격 | 필수 |
| F-04 | 종스크롤 배경(무한 반복 타일 지형) | 필수 |
| F-05 | 공중 적 3종 및 편대 스폰 | 필수 |
| F-06 | 지상 적 3종, 지상 폭격 판정 및 조준점 표시 | 필수 |
| F-07 | 충돌 판정(원형 또는 AABB) | 필수 |
| F-08 | 점수, 생명, 게임 오버 처리 | 필수 |
| F-09 | 타이틀 / 플레이 / 일시정지 / 게임 오버 화면 | 필수 |
| F-10 | 최고 점수 `localStorage` 저장 | 필수 |
| F-11 | 폭발/피격 파티클 효과 | 권장 |
| F-12 | 보스 및 스테이지 진행 | 권장 |
| F-13 | 효과음/BGM (Web Audio API로 간단히 생성) + 음소거 토글(`M`) | 선택 |
| F-14 | 아이템 드롭 | 선택 |
| F-15 | 창 크기에 따른 캔버스 반응형 스케일링 | 권장 |

## 5. 비기능 요구사항
- **성능:** 일반적인 노트북에서 60 FPS 유지. 화면 밖으로 나간 탄·적은 즉시 제거하고, 탄과 파티클은 오브젝트 풀로 재사용한다.
- **호환성:** 최신 Chrome/Edge/Firefox에서 동작한다.
- **코드 품질:** ES6 모듈(`type="module"`) 사용, 클래스/파일 단위 책임 분리, 매직 넘버는 설정 파일로 모은다.
- **오프라인:** 외부 CDN·네트워크 요청 없이 로컬 파일만으로 실행된다.
  (ES 모듈은 `file://`에서 막힐 수 있으므로 간단한 로컬 서버 실행 안내를 README 또는 본 문서에 명시한다.)

## 6. 기술 설계

### 6.1 폴더 구조
```
game01/
├── prd.md              # 본 문서
├── index.html          # 진입점, 캔버스 및 스크립트 로드
├── css/
│   └── style.css       # 레이아웃, 캔버스 스케일링, 폰트
└── js/
    ├── main.js         # 진입점, 게임 초기화
    ├── config.js       # 상수(해상도, 속도, 체력, 점수 등)
    ├── game.js         # 게임 루프, 상태(FSM) 관리
    ├── input.js        # 키보드 입력
    ├── player.js       # 플레이어
    ├── bullet.js       # 탄/폭탄
    ├── enemy.js        # 공중/지상 적, 보스
    ├── spawner.js      # 적 출현 패턴, 난이도 조절
    ├── background.js   # 스크롤 지형
    ├── collision.js    # 충돌 판정
    ├── particle.js     # 폭발 효과
    ├── hud.js          # UI 그리기
    └── audio.js        # 효과음 (선택)
```

### 6.2 주요 구조
- **게임 상태(FSM):** `TITLE`, `PLAYING`, `PAUSED`, `GAME_OVER`
- **엔티티 공통 속성:** `x, y, vx, vy, radius, hp, alive` 와 `update(dt)`, `draw(ctx)`
- **레이어 구분:** `air`(공중) / `ground`(지상)를 명시적으로 나누어 충돌 판정 시 공중 탄은 공중 적만, 폭탄은 지상 적만 검사한다.
- **렌더링 순서:** 배경 → 지상 적 → 폭탄/조준점 → 공중 적 → 플레이어 → 탄 → 파티클 → HUD

### 6.3 충돌 판정 표

| 공격자 | 대상 | 결과 |
|--------|------|------|
| 플레이어 공중 탄 | 공중 적 | 적 피해 |
| 플레이어 폭탄 | 지상 적 | 적 피해 |
| 적 탄 / 공중 적 | 플레이어 | 플레이어 피격 |
| 지상 적 본체 | 플레이어 | 충돌 없음 (지상이므로) |

## 7. 개발 마일스톤

| 단계 | 내용 | 완료 기준 |
|------|------|-----------|
| M1 | 프로젝트 골격: `index.html`, `style.css`, 게임 루프, 캔버스 스케일링 | 빈 화면에서 60 FPS 루프 동작 |
| M2 | 스크롤 배경 + 플레이어 이동/발사 | 끊김 없는 스크롤, 8방향 이동 |
| M3 | 공중 적 + 충돌 + 점수/생명 | 적을 쏴서 점수를 얻고, 맞으면 생명 감소 |
| M4 | 지상 적 + 폭탄 + 조준점 | 이중 공격 시스템 완성 |
| M5 | 타이틀/일시정지/게임 오버 화면 + 최고 점수 저장 | 전체 게임 흐름 완성 |
| M6 | 보스, 난이도 곡선, 파티클, 사운드 | 스테이지 클리어까지 플레이 가능 |

## 8. 완료 기준 (Definition of Done)
- `index.html`을 (로컬 서버로) 열면 타이틀 화면이 나타나고 Enter로 게임이 시작된다.
- 공중 공격/지상 폭격이 각각 올바른 대상에만 작동한다.
- 생명 소진 시 게임 오버 화면이 나오고 재시작할 수 있다.
- 최고 점수가 새로고침 후에도 유지된다.
- 콘솔 에러가 없고 60 FPS가 유지된다.

## 9. 리스크 및 고려사항
- **그래픽 리소스 부재:** 초기에는 Canvas 도형으로 표현하고, 이후 스프라이트 시트로 교체 가능하도록 그리기 코드를 엔티티 내부에 분리한다.
- **`file://` 모듈 제한:** 로컬 서버(`python -m http.server`) 실행 방법을 안내한다.
- **저작권:** 제비우스의 명칭·이미지·음원을 그대로 사용하지 않고, 게임 방식(메커니즘)만 참고한 오리지널 콘텐츠로 제작한다. 위 표의 적 이름은 내부 코드명이며 필요 시 변경한다.
